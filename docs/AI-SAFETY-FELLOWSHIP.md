# Africa AI Safety & Security Builder Fellowship — implementation note

This branch begins the technical implementation behind FINTIGEN's proposed capacity-building application.

## Funding alignment

The program is designed around a public-interest training pathway for people entering work related to risks from increasingly capable AI systems, with an initial emphasis on:

- AI assurance and evaluation;
- defensive information security;
- agent and tool security;
- human oversight and control;
- evidence, provenance, and uncertainty; and
- reproducible technical work samples.

## Current evidence

Already present in FINTIGEN before this branch:

- reusable interactive course player;
- labs and quizzes;
- persistent learner progress;
- AI and agentic-AI course content;
- community and career-center surfaces;
- certificates and learning dashboards.

Added in this branch:

- free `/learn/ai-safety-security` public-interest course;
- six modules with defensive labs and quizzes;
- `/ai-safety-fellowship` pilot page;
- explicit no-formal-degree prerequisite for the open pathway;
- pilot evaluation metrics;
- explicit status language preventing unverified claims about cohorts, mentors, partnerships, or outcomes.

## Claims discipline

This implementation does **not** claim:

- that a fellowship cohort is currently funded or running;
- that 30 participants have been selected;
- that specialist mentors have joined;
- that external AI-safety organizations are partners;
- that the course has produced career outcomes;
- or that the curriculum has been externally validated.

Those claims should be added only when evidence exists.
