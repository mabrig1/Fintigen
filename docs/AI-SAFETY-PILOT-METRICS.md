# AI Safety Fellowship — pilot measurement schema

The purpose of this measurement layer is to make a future fellowship pilot auditable without claiming causal impact from weak evidence.

## Learner-level instruments

### Baseline/final assessment

Five competencies are measured:

1. risk reasoning;
2. agent security;
3. evaluation design;
4. human oversight;
5. evidence discipline.

The browser prototype stores records locally. No server-side cohort collection is enabled in this branch.

A future cohort backend should collect only the minimum fields required for analysis and should separate identity/contact data from assessment data wherever practical.

### Capstone rubric

Capstones are reviewed across:

- research question and threat model — 20 points;
- evaluation method and reproducibility — 25 points;
- evidence quality and uncertainty — 20 points;
- security and responsible research practice — 15 points;
- interpretation and limitations — 20 points.

Total: 100 points.

## Program metrics

A funded pilot may report:

- number of applicants;
- number selected;
- number starting;
- number completing;
- baseline/final assessment distributions;
- capstone rubric distributions;
- number of mentor-reviewable work samples;
- number of public work samples where the learner separately consents;
- follow-on study, research, projects, fellowships, or relevant roles at defined follow-up intervals.

## Claims discipline

Do not present:

- pre/post score change as causal proof of training effectiveness;
- self-reported career outcomes as independently verified employment unless verified;
- public project counts without separating drafts, completed artifacts, and externally reviewed artifacts;
- aggregate metrics from learners who did not consent to the relevant use.

## Consent

Program participation, assessment, public-project consent, and consent for anonymized aggregate reporting should be separable choices.

Refusing public attribution or optional research use should not automatically exclude a participant from the learning program.
